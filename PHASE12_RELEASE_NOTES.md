# Phase 12 release notes

**Base:** `wishverse_site.zip` supplied by the operator. No data migration required.

**New:** optional Secret Wish Vault (three personalized gifts), recipient flip animations, one-click starters, local writing coach, extra Unicode share capacity, offline cache version bump.

**Compatibility:** previous greeting URLs without Vault fields decode and display normally; existing local drafts will be normalized with Vault disabled until deliberately enabled. No media upload or password protection.
